# promo 目录导航 (.ai_map.md)

Token Usage 1080p60 宣传片独立工程（48s / 2880 帧 / 120 BPM），采用纯确定性 DOM + Canvas 2D 帧调度渲染与 Python/FFmpeg 音画合成管线（已通过根 `sync.sh` 的 `--exclude="promo"` 排除，不随插件发布）。

## 目录结构

- `index.html`：1920×1080 舞台主入口（加载样式与脚本、挂载 `#bg-canvas`、`#stage` 舞台与 `#hud` 遥测覆盖层）
- `styles/`：视觉样式表（禁止 `@keyframes` 驱动视频关键动效）
  - `theme.css`：Obsidian Telemetry Cockpit 全局设计令牌、毛玻璃通用类、安全边距（左右 ≥ 72px，上下避让 HUD ≥ 72px/76px）、字体栈与 HUD 样式
  - `scenes-a.css`：第 1–3 幕视觉组件样式
  - `scenes-b.css`：第 4–7 幕视觉组件样式
- `js/`：确定性动画引擎与 7 幕分镜组件
  - `timeline.js`：暴露 `window.Promo`（常量、缓动/脉冲数学工具、格式化函数、`registerScene`）与 `window.renderFrame(frame, totalFrames, fps)`，负责异步挂载、URL `?t=`/`?play=1` 预览及 `window.__PROMO_READY__` 就绪标志
  - `assets.js`：暴露 `window.PromoAssets`，异步预加载 `/assets/logo.svg` 及 `/assets/icons/*.svg` 并通过 `getSvg(key, idSuffix)` 实现多场景 SVG ID 全量隔离
  - `backdrop.js`：暴露 `window.PromoBackdrop`，基于 `t` 确定性绘制深空基底、三色体积光晕、3D 透视网格、数据流光带、景深微粒与 Beat Drop / 切幕冲击波
  - `scene1_hook.js` ~ `scene3_overview.js`：第 1–3 幕（点火揭幕、实时上下文透视、全景 ROI 看板）
  - `scene4_security.js` ~ `scene7_outro.js`：第 4–7 幕（健康诊断与本地 DLP、多工具声纳雷达与归因账单、2× 分享卡与对话 Skill、星环收官）
- `audio/`：120 BPM 原创配乐与卡点音效合成模块（`synth_core.py`、`sfx_engine.py`、`generate_audio.py`）
- `render/`：零依赖 Chrome CDP 并行逐帧渲染与 FFmpeg 混流管线（`server.mjs`、`cdp_client.mjs`、`render_video.mjs`）
- `build/`：临时渲染与音频中间产物目录（`soundtrack_raw.wav`、`soundtrack.wav`、`keyframes/`）
- `poster.png` / `token-usage-promo.mp4`：宣传片高清封面与最终 H.264/AAC 成片
- `social-posts.md`：多平台图文推广推文合集（公众号/知乎/掘金深度长文、小红书/即刻种草、X 中英双语 Thread、V2EX/Linux.do 极客自荐、微信群/朋友圈短文案，内嵌 `../assets/screenshots/` 配图）
